# TeamLead's Sandbox

**TeamLead's Sandbox** — open-source база реальных управленческих кейсов для тренировки навыков IT-тимлидов.

Репозиторий можно использовать как самостоятельно (в Obsidian / любом Markdown-редакторе), так и в паре с **ИИ-агентом** (Claude Code, Cursor, Codex, Gemini CLI и др.), который работает как ментор и ролевой собеседник.

## Как начать тренировку с ИИ-агентом

1. **Клонируй или скачай репозиторий:**
   ```bash
   git clone <URL_РЕПОЗИТОРИЯ>
   cd "TeamLead's Sandbox"
   ```
2. **Открой папку в своём ИИ-инструменте** (Claude Code, Cursor, Codex и т.п.). Агент автоматически прочитает [`AGENTS.md`](./AGENTS.md) и [`CLAUDE.md`](./CLAUDE.md).
3. **Напиши агенту**, например:
   - *«Помоги выбрать кейс на делегирование»*
   - *«Давай пройдём Кейс 01 в режиме ментора, а потом отрепетируем разговор в ролевой игре»*
4. **Сохраняй свои решения** — агент запишет твои черновики, разборы и рефлексию в папку [`solutions/`](./solutions/).

## Что внутри

- [`cases/ru/`](./cases/ru/) — 10 кейсов для начинающих тимлидов (управленческий опыт `0–6 месяцев`, уровень `base`). Структура готова к добавлению кейсов для более опытных руководителей (`working`, `strong`) и английской версии `cases/en/`.
- [`competency-matrix.md`](./competency-matrix.md) — модель управленческих ролей и 7 компетенций с поведенческими индикаторами (источник: [Матрица компетенций](https://docs.google.com/spreadsheets/d/1SXW3fRNaV4a5SjNQWSxSteRuqwtLe_KiXPi4XfQ321A/edit?usp=sharing)).
- [`AGENTS.md`](./AGENTS.md) и [`CLAUDE.md`](./CLAUDE.md) — готовые инструкции для ИИ-агента (режим ментора + режим ролевой игры, правило без спойлеров).
- [`solutions/`](./solutions/) — твоё личное пространство для черновиков разговоров, договорённостей и рефлексии.

## Структура одного кейса

В каждой папке кейса лежат 5 файлов:
1. `01 — Кейс XX. ...md` — ситуация, дилемма и открытый вопрос.
2. `02 — Кейс XX. Проверка стратегии.md` — 4 реалистичных варианта действий (без спойлеров).
3. `03 — Кейс XX. Разбор стратегии.md` — разбор, управленческий инструмент и задание на черновик.
4. `04 — Что делать дальше.md` — шаг в реальную работу и форма рефлексии.
5. `agent-key.md` — ключи к тесту, критерии оценки ответа и сценарий ролевой игры для ИИ-агента.
