# Личные решения и артефакты (`solutions/`)

В этой папке сохраняются твои решения кейсов, черновики трудных разговоров, договорённостей и рефлексии после применения на практике.

Если ты работаешь с ИИ-агентом, он автоматически сохранит файл вида:
`solutions/case-01-YYYY-MM-DD.md`

## Шаблон файла решения

```markdown
# Кейс XX. <Название> — моё решение

- **Дата:** YYYY-MM-DD
- **Выбранная стратегия:** Вариант X
- **Ключевой инсайт из разбора:** ...

## Моё первичное решение
...

## Черновик разговора / действия / итоги ролевой игры
...

## Рефлексия после применения в команде (через 7 дней)
- Что именно я попробовал сделать?
- Что получилось, а что пошло не по плану?
- Что я сделаю иначе в следующий раз?
```

> **Совет:** если ты сделал публичный форк репозитория на GitHub, не коммить личные заметки из `solutions/` в публичную ветку, если в них есть чувствительные детали о твоей команде.
