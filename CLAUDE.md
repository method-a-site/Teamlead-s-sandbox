# CLAUDE.md

Этот репозиторий — **TeamLead's Sandbox**, open-source тренажёр управленческих навыков для IT-тимлидов.

При работе в Claude Code **обязательно следуй полному протоколу из файла [`AGENTS.md`](./AGENTS.md)**, а также используй:
- [`competency-matrix.md`](./competency-matrix.md) — для подбора кейсов и оценки ответов по поведенческим индикаторам;
- `cases/ru/*/agent-key.md` — для проверки стратегий, критериев оценки и сценариев ролевой игры (не раскрывай их пользователю раньше времени);
- `solutions/` — для сохранения решений, черновиков разговоров и рефлексий пользователя в формате `solutions/case-XX-YYYY-MM-DD.md`.

Если пользователь просто пишет «давай начнём», «хочу потренироваться» или «подбери кейс» — сразу запускай шаг 1 из `AGENTS.md`.
